# miProfio.es

Directorio de profesionales del hogar en España: búsqueda por oficio y ciudad, perfiles, reseñas, chat y contacto directo.

**Producto en producción:** [https://miprofio.es](https://miprofio.es)

Diseñado, programado y desplegado por [Mario Propios](https://github.com/mariopropios).

## Stack

- **Flutter** (web / PWA, base para Android e iOS)
- **Dart**, **Riverpod**, **Go Router**
- **Supabase** (Auth, PostgreSQL, Storage, Realtime)
- **Cloudflare Workers** (despliegue y dominio)
- **Firebase Cloud Messaging** (push)

## Qué incluye

- Autenticación y perfiles (cliente y profesional)
- Búsqueda, geolocalización y radio de servicio
- Reseñas con fotos, respuestas y ranking
- Chat en tiempo real (texto, imagen, audio)
- Notificaciones push y email
- PWA instalable

El código de la app está en [`buildjobs/`](buildjobs/). El `.env` de producción no está en el repositorio.
